BMaGlass Pay for Odoo

Same BMaGlass account. Same ZMW / USD wallets.

This provider connects Odoo to your existing BMaGlass Pay account through the BMaGlass Pay developer API. At checkout the buyer is redirected to a hosted BMaGlass payment page and pays wallet-to-wallet; settlement is confirmed instantly by BMaGlass's signed payment_link.paid webhook, with scheduled reconciliation kept as the fallback.

Honest limits: a live API key (bmp_live_...) is required to take payments — BMaGlass sandbox keys use simulated money by design, so they can never move real money. Only ZMW and USD are supported, the currencies BMaGlass wallets hold; no exchange rate is ever invented.
